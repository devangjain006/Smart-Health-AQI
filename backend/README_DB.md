This project includes a lightweight SQLite persistence layer for demo purposes.

How to create and use the database locally:

1. Create a Python virtual environment and activate it (Windows PowerShell):

   python -m venv .venv; .\.venv\Scripts\Activate.ps1

2. Install dependencies:

   pip install -r requirements.txt

3. Run the backend (this will create `aqi.db` in the `backend/` folder):

   uvicorn main:app --reload --port 8000

The app will initialize the database on startup. Readings and alerts are persisted as they are generated by the simulation loop.

Notes:
- This is intentionally minimal and suitable for local development or CI demos.
- For production, replace SQLite with a managed database and configure connection pooling and backups.
